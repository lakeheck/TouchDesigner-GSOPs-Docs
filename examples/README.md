# Examples

open `examples.toe` from the release .zip to view live examples in TouchDesigner

| Example | Description |
|---------|-------------|
| [Minimal Static Scene](gsop_static_scene_minimal.md) | The simplest possible GSOPs setup — load a splat and render it |
| [Minimal Particle Scene](gsop_particle_scene_minimal.md) | Load a splat, turn it into a particle system and render it |
| [Add Your Own Effects](gsop_static_splat_feedback.md) | Add custom animation, dynamics or logic using any other POPs |
| [Blowout Optimization](gsop_blowout.md) | Add space between splats to reduce overlapping geometry |
| [Thin Splat Optimization](gsop_thin_splat.md) | Reduce the splat count to improve render optimization |
| [Frustum Delete](gsop_frustum_delete.md) | Remove splats outside the camera's view |
| [Bounding Box](gsop_bounding_box.md) | Remove splats based on a bounding box or sphere |
| [Chroma Key](gsop_chroma_key.md) | Use color to select which splats are rendered |
| [Motion Blur](gsop_motion_blur.md) | Add 3D motion blur to splats |
| [Bokeh Texture Lookup](gsop_bokeh_texture.md) | Drive the bokeh effect with a TOP |
| [Bokeh Depth Slicing](gsop_bokeh_slice.md) | Use bokeh to slice through splats by depth |
| [Alpha Texture Lookup](gsop_alpha_texture.md) | Drive detail bias and alpha mix with a texture |
| [Relighting](gsop_relight.md) | Use TouchDesigner LightCOMPs with your splat |
| [Refraction](gsop_refract.md) | Add refractive geometry to your scene |
| [Equirectangular Render](gsop_equirectangular_render.md) | Render a full 360 panorama in a single pass |
| [Cubemap Render](gsop_cubemap_render.md) | Render six cube faces for immersive environments and reflections |
| [Splat Blending — Any to Any](gsop_splat_blending_any_to_any.md) | Blend between any two loaded splats in real time |
| [Splat Blending — Texture Input](gsop_splat_blending_texture.md) | Blend between splats using a texture-based input |
| [Attribute Blur](gsop_attribute_blur.md) | Blur an attribute across proximate splats |
